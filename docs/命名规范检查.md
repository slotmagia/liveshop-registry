# Registry 与命名规范

Registry **不是**业务发布模块，没有 `module.json` HTTP operation，不接 `verify-naming.ps1`。

对外机器路径保持现有契约，不发明第二套 URL：

- `POST /internal/v1/module-registry/releases`
- `POST /internal/v1/module-registry/activate`
- `POST /internal/v1/module-registry/deactivate`
- `GET /internal/v1/module-registry/routes`
- `GET /internal/v1/module-registry/modules`
- `GET /internal/v1/module-registry/capabilities`

gRPC 仍为 `liveshop.platform.v1.PlatformRegistryService`。
