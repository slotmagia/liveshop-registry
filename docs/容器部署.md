# Registry 容器部署

Registry 拥有模块不可变发布、活动版本、路由/能力快照，以及本地 gRPC 证书卷 `liveshop-grpc-certs`。

## 本模块脚本

在 `liveshop-registry` 仓库根：

```powershell
pwsh -File .\business\backend\tools\up-local.ps1
pwsh -File .\business\backend\tools\up-local.ps1 -Fresh
pwsh -File .\business\backend\tools\down-local.ps1
```

## 依赖顺序

```text
Registry → Identity → Gateway/Hosts → Platform / Catalog / Trade / Live
```

Identity 启动时拉取活动能力快照；Gateway 拉取路由快照。业务模块向本服务注册 origin。

## 端口与服务

| 服务 | 地址 |
|---|---|
| Registry HTTP | `http://127.0.0.1:18070` |
| Registry gRPC | `127.0.0.1:19070` / 容器内 `registry:19070` |
| Registry MySQL | `127.0.0.1:33075` / 容器内 `registry-center-db:3306` |

容器网络名：`liveshop-local`。证书卷名：`liveshop-grpc-certs`。容器内 MySQL 主机名必须是 `registry-center-db`：Platform 本地库仍占用 `registry-db`，同网同名会把 Registry 流量解析到 `liveshop_registry`。

## 常见失败

- Identity 报证书为空或 SPIFFE 失败：先完成本模块 `up-local.ps1`，再启动 Identity。
- 旧证书卷没有 `registry-server.pem`：脚本会 `-force` 轮换 CA，随后必须重启 Identity 与 Platform。
