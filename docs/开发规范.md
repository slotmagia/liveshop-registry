# LiveShop 通用开发规范（Registry）

> 位置：本仓库根目录 `docs/开发规范.md`  
> 适用范围：liveshop-registry  
> Registry 不是业务模块。完整 L1–L8 业务条文以各业务仓 `docs/开发规范.md` 为准；本文件只固定 Registry 边界。

1. Registry 是模块发布与活动快照的唯一事实源。Gateway 只读路由快照；Identity 只读活动能力快照。
2. 禁止拥有账号、授权、订单、商品或通知投递事实。
3. 禁止把注册写进 Gateway。浏览器不可达 `/internal/*`。
4. 进程配置只能来自 `-config` 指定的一份完整 YAML。
5. 不建 `protocol/` 目录；实现 `liveshop-protocol/platform` 已发布的 Registry 契约。
6. 无 `module.json`，不接业务 naming 检查。
